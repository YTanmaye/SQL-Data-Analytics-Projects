# 📊 SQL Project — Company Layoffs

## 📌 Project Overview

This repository contains two SQL projects developed as part of my Data Analytics learning journey, following **Alex The Analyst's “Learn SQL Beginner to Advanced in 4 Hours”** YouTube tutorial.

Using a raw company layoffs dataset, I practiced cleaning and transforming the data and then analyzing it to discover meaningful insights about company layoffs across different years, industries, and countries.

## 🚀 Projects Included

### 1. Data Cleaning Using SQL

Cleaned and prepared the raw layoffs dataset using MySQL by identifying duplicates, handling missing values, standardizing inconsistent data, and removing unnecessary records.

**Key Skills:** SQL, Data Cleaning, CTEs, Window Functions, Data Transformation.

### 2. Exploratory Data Analysis (EDA)

Analyzed the cleaned dataset to explore layoff trends across companies, industries, countries, and years. Calculated total layoffs, monthly rolling totals, and ranked the top five companies by layoffs for each year.

**Key Skills:** SQL, Aggregate Functions, GROUP BY, ORDER BY, CTEs, Window Functions, DENSE_RANK().
